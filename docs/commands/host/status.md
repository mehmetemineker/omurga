# `omurga host status`

## Use it when

You prefer a host-scoped health command while working through host setup.

```bash
sudo omurga host status
sudo omurga host status --json
```

This is the same health check as [`omurga doctor`]({{ '/commands/doctor/' | relative_url }}).
