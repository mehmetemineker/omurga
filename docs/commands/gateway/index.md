# Gateway commands

Omurga generates project route snippets and imports them into the system
Caddyfile.

| Goal | Command |
| --- | --- |
| List generated routes | [gateway list](list/) |
| Check Caddy service | [gateway status](status/) |
| Validate configuration | [gateway validate](validate/) |
| Apply a validated reload | [gateway reload](reload/) |

## Scenario: a domain is not routing

```bash
sudo omurga gateway list
sudo omurga gateway validate
sudo omurga project render ./demo --kind caddy
sudo omurga gateway reload
```

For a public HTTPS route, point DNS to the host and configure `https: true` in
the project gateway route.
